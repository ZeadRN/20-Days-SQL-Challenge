# 20 Days of Data Analytics Learning

I am documenting my learning as I build the foundations for becoming a data analyst. This repository contains daily notes, examples, and interview revision questions from my 25-day learning series.

My goal is to understand the concepts, explain them clearly, and gradually apply them through practical exercises.

## Day 1 highlights

- Database, DBMS, and RDBMS fundamentals.
- SQL command categories.
- Keys and table relationships.
- ACID properties and transactions.
- SQL versus NoSQL databases.
- Data warehouses, lakes, and lakehouses.
- Logical processing order of SQL queries.
- Redundancy and an introduction to normalization.
